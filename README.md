# CRM Demo Frontend

Diese kleine Vite/React-App zeigt einen klickbaren, rein lokalen Demo-Mitarbeiterbereich (Zeiterfassung, Urlaub, Kalender, Profil & Aufträge).

## Entwicklung starten

1. Abhängigkeiten installieren:

   ```bash
   npm install
   ```

2. Dev-Server starten:

   ```bash
   npm run dev
   ```

3. Browser öffnen und die angezeigte localhost-URL aufrufen.

> Hinweis: Das UI nutzt Utility-Klassen per Tailwind-CDN (siehe `index.html`).
